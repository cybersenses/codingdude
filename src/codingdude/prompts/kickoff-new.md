## Kickoff (new project)

This workdir has no code yet — this is the start of a new project. Do not
write code or scaffold anything until the shape of the project is
confirmed:

1. Interview the user with ask_user before anything else: what the project
   is and who it is for; the language, framework, and stack (offer a
   recommendation if they have none); where work will be tracked; the
   test/build commands they want; and any constraints (platform,
   deployment, licensing).
2. Summarize the answers back as a short project brief and confirm it.
3. Only after confirmation: propose the scaffold and an initial ROADMAP,
   then await approval before generating files.

If the user's message below already answers some of these questions, do
not re-ask them — start the interview from what is still open.
